# IP risks of publishing a commercial mobile game named "Wumpus Adventures" (based on Hunt the Wumpus)

Not legal advice. Trademark databases (USPTO, EUIPO TMview, WIPO Brand DB, SENADI) were not directly queried (JS apps / not fetchable via the tools available); web-search proxies only. Owner must run the searches listed in the Gaps.

## 1. Discord / "Wumpus" trademark collision

### Takeaway
Wumpus is Discord's mascot (Wikipedia: character believed to originate from the 1973 game). I found no confirmed USPTO/EUIPO/WIPO registration for the word WUMPUS itself, but could not query the registers directly, so absence is unverified. Discord's DISCORD word mark is registered for downloadable game software, and its brand page forbids confusingly similar marks only for "Discord Marks", with no stated rules for the mascot. Risk is moderate-low but unverified; "Wumpus" is also a generic historic game-creature name predating Discord (1973).

### Cited Findings
- Wumpus is Discord's mascot; the character's origin is believed to be the 1973 game Hunt the Wumpus — [Wikipedia: Wumpus](https://en.wikipedia.org/wiki/Wumpus) (via search summary)
- Discord holds U.S. Reg. No. 6254199 for DISCORD (granted Jan 2021) covering downloadable game software and gaming social networking; other pending DISCORD filings incl. a 2024 design mark of unknown content — [Justia](https://trademarks.justia.com/885/31/discord-88531358.html), [Justia 2](https://trademarks.justia.com/981/31/discord-98131687.html), [Justia 3](https://trademarks.justia.com/975/01/discord-97501815.html)
- Discord brand page: Discord Marks and Brand Assets belong to Discord Inc.; permission required except as guidelines permit; do not incorporate the Discord Marks "or any mark that is confusingly similar" into a brand/product name (incl. bots) or trademark; use must not imply affiliation. Wumpus appears only as image files in Brand Assets, with no separate third-party guidance on the name — [Discord Branding](https://discord.com/branding)
- A WIPO UDRP decision (D2021-0893) surfaced in search for Discord/Wumpus-related terms; I did not open it, so its relevance is unverified — [WIPO](https://www.wipo.int/amc/en/domains/decisions/text/2021/d2021-0893.html)

### Inferences
- Using Discord's Wumpus mascot art/likeness (blue-ish round creature) would be the real risk; a name alone for a cave-hunting puzzle game is less likely to be confusing, but a title consisting solely of "Wumpus" plus a cute mascot invites association. Avoid Discord-like colors/character design.
- Class 9/41 overlap exists with Discord's game-software coverage, but only for the DISCORD mark.

### Gaps
- No evidence found either way of Discord enforcement against apps named Wumpus (searched once; not exhaustive).
- Registers not checked. Owner to run: USPTO https://tmsearch.uspto.gov (search "wumpus", owner "Discord Inc."); EUIPO TMview https://www.tmdn.org/tmview; WIPO https://branddb.wipo.int (text "wumpus", also look for design marks). Check classes 9, 41, 28.

## 3. Copyright / trademark status of Hunt the Wumpus

### Takeaway
Hunt the Wumpus (Gregory Yob, 1973, BASIC) mechanics and ideas are not protectable; only specific code/expression is. No known claims found. Source was published in Creative Computing (1975) and many clones exist.

### Cited Findings
- Created 1973 by Gregory Yob; PCC distributed; source published in Creative Computing Oct 1975 and PCC's 1977 book; sequels Wumpus 2/3 by Yob; Ken Thompson C version in bsdgames; commercial TI-99/4A version 1981 — [Wikipedia](https://en.wikipedia.org/wiki/Hunt_the_Wumpus)
- Wikipedia page states no copyright holder or license for the game and categorizes it as "public-domain software with source code" without explanation — same source (do not rely on this as legal status)
- US Copyright Office Circular 33 "Works Not Protected by Copyright" exists at https://www.copyright.gov/circs/circ33.pdf; I could not extract text (PDF unreadable, HTML 404). Well-known position there: ideas, rules and methods of play are not protected, nor are names/titles — verify by reading it.

### Inferences
- Reimplementing the cave/bats/pits/arrows mechanics from scratch is low risk; do not copy Yob's original text, 1975 source listing, or Treasure/other modern clone art/text.

### Gaps
- No claims or enforcement by Yob's estate found, but not systematically searched. Circular 33 quote unverified.

## 4. Clearance workflow and registration costs

### Takeaway
Run knock-out searches in USPTO, TMview, WIPO BrandDB and SENADI (formerly IEPI) before committing. US base application is $350 per class; Ecuadorian fees found were old.

### Cited Findings
- USPTO base application fee $350 per class since Jan 18, 2025; +$200/class if not using ID Manual wording; +$200 per extra 1,000 chars; +$100/class for missing info — [Foley/FR](https://www.fr.com/insights/thought-leadership/blogs/new-uspto-trademark-fees-go-into-effect-january-18-2025/), [Mondaq](https://www.mondaq.com/unitedstates/trademark/1551148/uspto-set-to-change-trademark-fees-alongside-patent-increases-in-2025)
- Ecuador: IEPI is now SENADI. Cámara de Comercio de Guayaquil-style guide lists ~US$16 phonetic search and ~US$116 registration filing tax (undated, likely outdated); ~6 months process; 2005 WIPO report gave 8 USD for search — [Elyex guide](https://elyex.com/como-registrar-una-marca-en-ecuador/), [WIPO](https://confluence.wipo.int/confluence/x/ngjBAw)

### Inferences
- A two-class US filing (9 and 41) would be roughly $700 USD in government fees if using ID Manual wording.

### Gaps
- Current SENADI fee table not verified (check https://www.derechosintelectuales.gob.ec). Madrid/EUIPO fees not researched.

## 5. Asset licensing, AI policies, and "Wumpa"

### Takeaway
Keep license proof for every asset. AI-generated assets are weakly copyrightable in the US and platforms impose content-safety and (on Steam) disclosure duties. Avoid "Wumpa", which is a Crash Bandicoot fruit term.

### Cited Findings
- US Copyright Office AI Report Part 2 (Jan 29, 2025): prompts alone do not give authorship; AI-assisted works protectable where human-authored expression is perceptible or humans creatively arrange/modify outputs — [Baker Botts](https://ourtake.bakerbotts.com/post/102jxrk/copyright-office-releases-part-2-of-artificial-intelligence-report), [IPWatchdog](https://ipwatchdog.com/2025/01/29/part-two-copyright-office-ai-report-says-creative-prompting-doesnt-constitute-authorship/)
- Google Play AI-Generated Content policy: generative AI apps must not produce offensive/restricted content and must provide in-app reporting of offensive AI content; policy applies to apps generating content from prompts, not to apps merely shipping AI-made art (reading of summary) — [Google support](https://support.google.com/googleplay/android-developer/answer/14094294), [9to5Google](https://9to5google.com/2023/10/25/google-play-gen-ai-policy/); third-party analysis says no express duty to disclose AI use in description, marketing must be accurate — [Revera](https://www.revera.legal/?p=3557)
- Apple guideline 5.1.2(i) (Nov 2025) requires disclosure and consent when sharing personal data with third-party AI — [TechCrunch](https://techcrunch.com/2025/11/13/apples-new-app-review-guidelines-clamp-down-on-apps-sharing-personal-data-with-third-party-ai); a claim that Apple requires labeling AI-generated content comes from a blog and is unverified — [promise.legal](https://blog.promise.legal/ai-game-assets-copyright-steam-disclosure-2026/)
- Wumpa is the central collectible in Crash Team Rumble; Activision's trademark notice lists CRASH BANDICOOT, CRASH TEAM RUMBLE, not Wumpa; no Wumpa registration was found — [Wikipedia](https://en.wikipedia.org/wiki/Crash_Team_Rumble), [TrueAchievements](https://www.trueachievements.com/products/71284/Crash-Team-Rumble)

### Inferences (checklist)
- For each audio/sprite/font asset store: source URL, author, license text snapshot (archive/PDF), date downloaded, purchase receipt; CC0 needs no credit; CC-BY needs attribution (author, title, source, license link) in credits screen and store notes; avoid NC/ND/SA licenses for commercial use; "royalty-free" packs need EULA check for redistribution inside apps and engine-embedded use.
- For AI assets: keep prompts, tool name/version, ToS commercial-use clause, and your human edits; assume little copyright protection for raw output.
- Avoid "Wumpa" in file names, code and content; rename the mascot/items to original terms.
- Avoid Discord-like Wumpus art.

### Gaps
- Apple's primary text on AI content labeling, Google Play current text, and Steam's AI disclosure rules not verified. CC license terms not researched (standard knowledge: creativecommons.org/licenses).
